# Audiobook Reader v0.1.0

First native M4B playback preview with brushed-aluminum bookshelf theme, FFmpeg/SDL2 audio, chapter skip, seeks, favorites, stored position, controller navigation, and an independent installation directory.

**Install:** Extract `PPSA99784.zip` to `/data/homebrew/`; place DRM-free `.m4b` files in `/data/AudioBookReader/Books/` or `/download0/Books/`. Use the compatible PS5 homebrew loader to register the title.

**Known limitations:** FairPlay/DRM is not supported. Certain sandboxed USB paths may not be readable. Native playback requires a compatible FFmpeg/SDL2 runtime and console validation.
