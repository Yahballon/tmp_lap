EBOOK READER - LOCAL BOOK LIBRARY

Place your own legally obtained .epub or .pdf files in this folder.
When installed on PS5, this folder is:
  /data/homebrew/PPSA99741/assets/Books

The Ebook Reader accesses these files through:
  /app0/assets/Books

If /mnt/usb0/Books reports "Operation not permitted" in the app,
copy the EPUBs using a compatible, already-authorized FTP/file manager
to this folder. Restart Ebook Reader and press OPTIONS to rescan.

Do not delete this folder when updating the app. Make a backup first.
