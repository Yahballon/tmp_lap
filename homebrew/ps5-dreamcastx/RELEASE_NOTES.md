# PS5DreamcastX v0.1.0

First native PS5 port integration by YAHBALLON.

## Changes

- **Dreamcast emulation.** Uses the proven native PSFlycast SH-4/AICA/GD-ROM emulation and Vulkan/RADV rendering.
- **Cover-flow UI.** A PS5GBAX-inspired 3D game-case carousel with angled neighbours, selection glow and reflections.
- **Independent title.** PPSA99765 and isolated app folders/metadata.
- **Build automation.** Dedicated tmp_lap GitHub Actions workflow, signed PS5 packaging and ZIP validation.

No commercial games, keys, BIOS or firmware are distributed.
This release should only be published after the native CI build succeeds.
Hardware compatibility still needs a real PS5 test.
