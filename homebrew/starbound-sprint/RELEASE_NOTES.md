# Starbound Sprint v0.2.0

## New features
- Double jump: press Cross, release, then press Cross again while airborne.
- Limit to two jumps per landing; an extra tap cannot produce a third jump.
- Show remaining jumps in the in-game HUD.
- Landing, checkpoint respawn, and stage changes restore jump availability.
- Launch-pad boosts and enemy stomp bounces permit a subsequent midair jump.
- Prevent menu confirmation Cross from automatically consuming a jump.

## Installation
Download `PPSA99641.zip`, extract the full `PPSA99641/` folder to `/data/homebrew/`, replacing the previous application files while **preserving** `starbound-progress.cfg`. Re-register in your compatible loader if necessary.

## Compatibility
Title ID `PPSA99641` unchanged. Existing progress format stays compatible.

## Known limitations
Actual controller handling and gameplay must be verified on PS5 hardware. Audio is not implemented in this version.
