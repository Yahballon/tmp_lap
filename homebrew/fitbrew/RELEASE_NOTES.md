# FITBREW v0.1.0 — Initial PS5 Test Build

First offline bodyweight fitness homebrew by YAHBALLON.

- Native controller-driven home, workouts, progress, programs, settings, details and session screens.
- 36 equipment-free exercises, 12 curated workouts with work/rest intervals.
- Exercise form tips, easier variations and local completion/streak records.
- Six themed exercise artwork cards and package launcher tile (fallback generated until final photography integrated).
- Unit tests, native PS5 cross-compilation and ZIP verification workflow.

**Testing:** This version is NOT hardware-validated yet. Exercise images/typography, menus, pacing, console-specific storage and GPU rendering need user PS5 testing. This is an experimental TESTBUILD; not a consumer-ready fitness recommendation.
