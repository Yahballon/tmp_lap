# Standby Clock v0.1.0

Initial native PS5 homebrew test build. Real-time digital and analog clocks, seven-day calendar strip, alarm with dismiss and five-minute snooze, four themes, brightness overlay, 12/24-hour format, local/fixed UTC offset, optional pixel shift, and persistent settings.

**Unverified:** PS5 console boot and system clock timezone correctness. Alarm is an in-app on-screen alert, not a background wake alarm; it does not work when the app is closed or the console is asleep. Sound is not implemented.
