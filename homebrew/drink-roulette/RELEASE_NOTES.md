# Drink Roulette v0.1.0 — First Playable Test

First native offline PS5 drinking/party roulette application. Includes 10 colored wheel segments, animated bottle spinner, 48 original English challenges, 2–8 local pass-and-play players, player ready flags, round counter, modes, settings persistence and gamepad navigation. All drink actions are optional, with non-alcoholic alternatives. Original vector-rendered UI; optional user-provided menu reference background.

Install an Actions-built `PPSA99841.zip` into `/data/homebrew/` using an existing compatible loader.

This build is not claimed to have passed physical PS5 testing until verified on hardware.
