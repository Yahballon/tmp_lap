# Drink Roulette v0.1.2

- Native PS5 first-launch setup: 2–8 players, editable names using an integrated DualSense keyboard, game mode, intensity, and ready lobby.
- Expanded offline challenge library from 48 to **433 unique questions, dares and group prompts**; includes non-alcoholic/pass options and prompt de-duplication.
- Five functional modes: Standard, Wild, Couples, Quickfire, Truth & Dare; three functional challenge tiers.
- Rebuilt lobby with expanded left-side player list, updated neon reference artwork, cleaned lower-right corner, and live status panel with true eligible challenge count.
- Transparent green glass bottle sprite replaces primitive single-color polygon and rotates across the PS5 OpenGL roulette wheel.
- Persist selected options, names, and onboarding status. Existing v0.1.1 user settings trigger a fresh setup on first v0.1.2 launch.
- Automated CI builds installable `PPSA99841.zip`, checks included texture assets and runs game-engine regression tests.

Physical PS5 rendering and gamepad behavior still require a user hardware test; no such test is claimed here.
