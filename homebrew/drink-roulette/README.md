# Drink Roulette by YAHBALLON — v0.1.1

Native, **offline**, controller-first PS5 party game, inspired by the supplied 16:9 neon-roulette menu screenshot. This is a playable OpenGL homebrew project, **not a web page** or a static game mockup.

## Implemented

- Full 1920×1080 responsive PS5 game UI with glowing wheel, bottle spinner, title, main menu, player list, rules, challenges, settings and challenge-result screen.
- Physics-style eased bottle animation: five to eight rotations in 3.5–4.8 seconds, randomized wedge and challenge, DualSense rumble on landing.
- Seven categories across ten wedges: Truth, Dare, Shot, Pass, Cheers, Group Drink and Drink.
- 48 built-in English prompts; mixed silly tasks, questions, optional drinking, and non-alcoholic alternatives.
- Single-controller **pass-and-play**: 2–8 players, readiness toggles, 12 preset names, round and turn counter.
- Mode selection (Standard or Chill) and 15/30/Endless rounds, atomic INI persistence, local diagnostic log.
- Optional `assets/menu_background.jpg` is the exact user-supplied artwork (included in the downloadable source ZIP from this conversation); procedural artwork is generated by `assets/generate_assets.py` for CI and as a fallback when the optional background is absent.
- No network, login, streaming, console privilege escalation, or real-money mechanics.

## Controller

| Control | Action |
| --- | --- |
| D-Pad / left stick | Navigate menu and lists |
| Cross | Confirm / ready / spin / next turn |
| Circle | Back; in main menu, exit confirmation |
| Square (Players) | Cycle preset player name |
| Left / Right (Players) | Reduce / increase player count (2–8) |
| Triangle (Game) | Restart current session |
| Options (Home) | Settings |

Only one DualSense is needed: hand it to the next person each round. The game does not claim to bind 4 physical controllers.

## Build and installation

The GitHub Actions workflow `.github/workflows/build-drink-roulette.yml` copies [`Yahballon/PS5-DevBridge`](https://github.com/Yahballon/PS5-DevBridge) `templates/simple-calc`, adds the native C++ sources and generates a 512×512 app icon, preparing OpenGL SDK with `tools/prepare-opengl.sh`. A validated build produces an installable `PPSA99841.zip`.

Copy its `PPSA99841/` directory to `/data/homebrew/` on an already homebrew-capable PS5, and register it using a compatible existing loader. Metadata ID: `PPSA99841`, content ID `UP9000-PPSA99841_00-DRINKROULETTE001`. Saved settings and logs live in `/data/DrinkRoulette/`.

To use **the exact reference look**, add the supplied `menu_background.jpg` to `app/assets/` during preparation; on-console the game loads it from `/app0/assets/menu_background.jpg` or `/data/homebrew/PPSA99841/assets/menu_background.jpg`. If omitted, the original generated party scene is rendered instead. Build workflow copies the optional reference photo if the file is present in the repo; The checked-in image is included in CI-produced PS5 ZIPs.

Host test: `g++ -std=c++20 -Wall -Wextra -Werror homebrew/drink-roulette/tests/game_test.cpp -o /tmp/drink-test && /tmp/drink-test`.
