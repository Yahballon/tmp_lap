# ThemeChanger v0.3.16 – Integrated Signal Companion



- New Signal Companion sidebar entry with Status, Colour and Startup tabs.

- Start/restart the bundled ps5-signal service on demand, check status, and test console lights and beeper.

- Mix blue/white/amber LED channels, keep a colour, restore system colour and store six personal presets.

- Edit, preview and save startup beep/light sequences with upstream validation limits.

- Optional ps5-autoloader integration preserves other payload entries.

- Reuses Marice’s GPL Signal Companion backend with attribution and a pinned, loopback-only ps5-signal build.

- Preserves wallpaper downloads, cleanup, custom app icon and layout from v0.3.15.



Hardware validation is still required for the console LEDs/beeper and the payload on each firmware. Start the service explicitly from the Signal Companion Status tab; a jailbreak ELF loader on port 9021 is required.
