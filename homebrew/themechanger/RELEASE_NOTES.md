# ThemeChanger v0.1.0

Native PS5 theme selector with twelve original illustrated backgrounds and LiveShell Engine API integration.

- PS5 OpenGL renderer from BlackBearReloaded's ps5-homebrew-ui via PS5-DevBridge
- D-pad/left stick, Cross, Circle, L1/R1 navigation
- Twelve generated 720p H.264 wallpapers plus PNG previews
- Installer ZIP: PPSA99891.zip
- Requirements: jailbreak, ShadowMountPlus/compatible loader, running ZiZc3 LiveShell payload
- The preview is illustrative; ThemeChanger does not alter the official PS5 menu tiles.
- To actually play a wallpaper behind the home screen, install and start a compatible LiveShell payload separately.
- Native hardware execution remains to be tested on PS5.
