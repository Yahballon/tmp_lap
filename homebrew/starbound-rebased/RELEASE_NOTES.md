# Starbound Rebased v0.1.6 – Repair blank blue screen by fixing resource paths

Real PS5 hardware shows SDL2 software rendering, video presentation, and the first two game loops all working. The game only draws a blue rectangle because the engine searches `res/sprites/`, `res/fonts/`, `res/data/`, and `res/sounds/` relative to `/app0/assets`, while prior ZIPs packaged them as `assets/sprites/`, `assets/fonts/`, etc. The build now preserves `assets/res/**`, checks the actual ZIP paths and validates the 25×15 menu CSV. A PS5 startup log records `ASSET00` to `ASSET04` confirming CWD and resource availability. This release is not yet hardware-verified for menu display; it keeps PPSA99642 and TESTBUILDS update compatibility.
