# Starbound Rebased v0.1.5 — Black screen and first-frame crash investigation

Hardware feedback proves v0.1.4 reaches `Core::run`, but subsequently black-screens and crashes. The PS5 SDL2 video event pump invokes `PS5_Keyboard_PumpEvents` every iteration even though keyboard initialization was disabled in v0.1.4. The upstream implementation unconditionally invokes IME system APIs; this build disables that unused polling function as well. Includes separately authored missing menu background data, guards SDL font-to-texture conversion failures and traces the first two game frames (`LOOP01`–`LOOP06`, `RENDER01`–`RENDER04`) in `/data/starbound-rebased/boot.log`. Both SDL software rendering and VideoOut are still to be validated on hardware. This update is experimental, not a confirmed run-time fix.
