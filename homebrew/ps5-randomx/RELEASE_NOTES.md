# PS5 RandomX Benchmark by YAHBALLON v0.6.1

## Critical safety hotfix — PS5 freeze during full-memory init

Real-console feedback: v0.6.0 AUTO 10 completed earlier light tests but the last full-memory stage became unresponsive and required a console reboot. Uploaded logs do not contain a complete v0.6.0 full-memory benchmark receipt; a precise failure instruction or resource limit is not established.

- On launch **AUTO SAFE 7 — ONE CLICK** is preselected. Press **X once** to run four interpreter-light profiles then 1/2/4-thread secure JIT Light automatically. All seven profiles have been successfully measured on hardware in earlier releases.
- **All full-memory profiles are fail-closed in the supervisor before cache/dataset allocation**. Selecting any full-memory individual profile or legacy AUTO FULL produces a clear error and exits the test without attempting the >2 GiB allocation.
- Restores safe normal controller response and cancellation of ordinary runs. A system-level stall cannot be interrupted reliably, hence the memory-heavy code is not executed.
- Keeps all JIT correctness checks and existing AUTO benchmark logging. The `auto_kind=safe7-light-jit` aggregate contains the measured scores.
- This hotfix intentionally does **not** claim to implement full-memory mining. Reintroducing full memory requires a separate, cautious console memory availability test and staged runtime validation, ideally with a dedicated memory test app or strict external protection.
