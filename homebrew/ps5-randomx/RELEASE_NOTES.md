# PS5 RandomX Benchmark by YAHBALLON v0.1.0

First experimental native PS5 benchmark for PS5Coin research.

- Real upstream RandomX 1.2.1 light/interpreter hashing (1 worker, software AES).
- Selectable 10/30/60-second runs with live measured H/s, hashes and progress.
- Responsive controller UI during cache preparation and hashing; cancel support.
- Result log in `/data/ps5-randomx/benchmark.log`.
- New independent PS5 Title ID **PPSA99795**.
- **This is not cryptocurrency mining, a coin launch or an implementation of a blockchain.**
- **Not yet validated on actual hardware**; share a screenshot or log after testing.
