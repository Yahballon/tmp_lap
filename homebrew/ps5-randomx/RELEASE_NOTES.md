# PS5 RandomX Benchmark by YAHBALLON v0.4.3

## Hardware trace finding

On real PS5 native homebrew v0.4.2, **JIT VM INIT ONLY** and **1 THREAD / SECURE JIT** both stop inside the JIT constructor: it successfully requests and maps **77,824 bytes** of code memory, then crashes when trying to copy the **256-byte static assembly prologue**. This happened in two independent sessions. W^X RW->RX->RW permissions test continues to pass, but does not prove the 77,824-byte mapping or source assembly code can be read.

## Changes

- Adds a separate **JIT 78 KiB BUFFER PROBE** profile **at the end of the selector**, index **8**. No RandomX VM construction or JIT execution. Tests actual 77,824-byte anonymous RW mapping, writes the first and last byte, copies a 256-byte known stack pattern via `memcpy`, then validates the result.
- Reports each operation to `/data/ps5-randomx/jit_trace.log`. A failed test or crash identifies which buffer access failed.
- Captures **full 64-bit source/destination addresses** from the real RandomX JIT constructor. The trace file includes `jit_source_addr` and `jit_dest_addr`.
- Uses a **volatile byte-by-byte copy** of the original static assembly prologue with checkpoints every 32 bytes instead of optimized `memcpy`. The copied bytes are unchanged; this can distinguish a memcpy implementation issue from inaccessible source/target memory.
- Adds explicit first-byte destination write and source read checkpoints before the prologue copy.
- All existing benchmark profiles, including the default **AUTO 4 LIGHT**, remain intact and never execute JIT.
- PS5 source retains upstream RandomX v1.2.1 and the original crypto semantics, no blockchain/miner functionality.

**Test order**: First try `JIT 78 KiB BUFFER PROBE` (profile 8, one step past Secure JIT). Send its results. Only after that probe succeeds, attempt `JIT VM INIT ONLY` (profile 6) on a console suitable for homebrew debugging. Do not run secure JIT hashing yet; it is still crash-prone.

v0.4.3 is a debugging build; a successful compiler or Linux test does not prove the console's JIT works. Title ID `PPSA99795`, installer `PPSA99795.zip`, TESTBUILD index generated by GitHub Actions.
