# PS5 RandomX Benchmark by YAHBALLON v0.5.0

## One-click AUTO SECURE JIT benchmark

On PS5 native v0.4.4, an actual 30-second **1 THREAD / SECURE JIT** test completed: 1,166 hashes in 30.011 seconds, **38.8520 H/s**, **jit_vector_ok=1**, `status=completed`. The secure JIT VM was also destroyed successfully. The preceding 1-thread Light interpreter measured ~1.97 H/s, for roughly **19.7×** 1-thread improvement. Multi-thread Secure JIT has NOT yet been measured on the actual PS5.

This release adds:
- **AUTO 3 SECURE JIT**, opt-in at the third selection from app launch (**Down twice, then X**), with 1, 2, and 4 worker runs in sequence. Each uses the chosen 10/30/60 second duration and checks JIT output against the independent interpreter for **every individual worker** before timed hashing.
- **2 THREADS / SECURE JIT** and **4 THREADS / SECURE JIT** standalone profiles, also opt-in at the end of the manual list.
- A fail-closed JIT verification latch. If **any** worker's JIT hash differs from the interpreter, the run is marked failed and no timed benchmark begins.
- An automatic aggregate log report (`auto_kind=secure-jit`) detailing profile, hashes, elapsed time, H/s and outcome for 1/2/4-thread runs.
- Progress and result summary rendered in the app UI after one button press; cancel entire sequence with Circle/Options.
- **AUTO 4 LIGHT** stays the unchanged default; **AUTO ALL 5** remains an independent opt-in full-memory benchmark (>2 GiB).
- Keeps the read-only assembler template mirror that solved the previously observed PS5 execute-only text crash; no OS security bypass, no actual coin network or mining.

**PS5 test instruction:** Update TESTBUILD, run **AUTO 3 SECURE JIT**, inspect `/data/ps5-randomx/benchmark.log` for each profile's `jit_vector_ok=1` and `auto_status=completed`. A working 1-thread JIT does not guarantee that higher concurrency will be stable or that scaling will be linear; this remains a homebrew test on a console you are prepared to debug. Do not combine JIT with Full Memory at this stage.
