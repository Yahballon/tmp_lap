# PS5 RandomX Benchmark by YAHBALLON v0.6.0

## One-click AUTO 10 — press X once
The default mode now launches ten genuine RandomX benchmarks in sequence, with no manual switching:

1. Light interpreter, 1 thread, software AES
2. Light interpreter, 1 thread, hardware AES
3. Light interpreter, 2 threads, hardware AES
4. Light interpreter, 4 threads, hardware AES
5. Light secure JIT, 1 thread
6. Light secure JIT, 2 threads
7. Light secure JIT, 4 threads
8. Full-memory secure JIT, 1 thread
9. Full-memory secure JIT, 2 threads
10. Full-memory secure JIT, 4 threads

All use the selected per-profile duration (default 30 seconds). Individual results and an aggregate summary are appended to `/data/ps5-randomx/benchmark.log`. Progress and up to ten results appear across two columns in the UI. Cancel with Circle or Options.

**Verified PS5 baseline (v0.5.0):** 1/2/4-thread light secure JIT = 38.11/75.29/144.03 H/s, with hash correctness confirmed. **Full-memory secure JIT has not yet been measured on PS5.** It requires a ~2,080 MiB dataset plus cache and working memory, initialized before each full-memory test. OS-level memory kills or crashes cannot be ruled out; a normal allocation failure is reported and stops the suite without hiding the error. Hash verification is performed before timing each worker; no silent fallback.

The earlier smaller AUTO modes remain available from the selector. The app is still a benchmark, not a cryptocurrency, miner, wallet, or payout network. Release tag `ps5-randomx-v0.6.0`, Title ID `PPSA99795`. TESTBUILD `version.json` is generated by GitHub Actions, never edited manually.
