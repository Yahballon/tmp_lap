# Snake by YAHBALLON v0.1.0

Initial native PlayStation 5 homebrew edition.

- Screenshot-inspired neon jungle main menu, right-side quick settings and animated in-game pixel-snake grid.
- Modes Classic, Zen and Sprint; adjustable speed and walls; three kinds of food.
- Local persistent high score, pause/restart, controller navigation and game-over screen.
- Original build-time icon / background generator, host gameplay tests, native OpenGL packaging.
- Target Title ID: PPSA99846. Firmware compatibility depends on your existing homebrew loader.
- Note: PS5 hardware testing is not included in automated CI.
