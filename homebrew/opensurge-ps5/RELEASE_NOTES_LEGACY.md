# Open Surge PS5 v0.1.1 — native bootstrap test only

This is a **non-playable** PS5 homebrew diagnostic created with PS5-DevBridge and ps5-homebrew-ui native OpenGL, using the older working build pipeline.

- Ships the genuine, pinned upstream Open Surge 0.6.1.3 art, sprites, scripts, fonts, music, levels, quests, licenses and checksums.
- DualSense read/exit controls and native OpenGL UI.
- On-PS5 game asset file access checks, recorded at /data/OpenSurge/legacy-port.log.
- No actual game engine, title-screen flow, levels, audio engine, saves or Open Surge gameplay yet.

Only use to verify title mounting and the native renderer. A successful GitHub Actions build does not verify console playability.
